# resultados-corretoras

Painel gerencial de resultados de corretoras (dashboard estático).

## Conteúdo

- [`painel_corretoras.html`](painel_corretoras.html) — painel com gráficos (Chart.js).

## Deploy

Site estático publicado na **Vercel**. O arquivo [`vercel.json`](vercel.json) faz a raiz (`/`) servir o painel automaticamente.

Cada push na branch `main` dispara um novo deploy.
